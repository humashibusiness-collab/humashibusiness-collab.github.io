# Humashi Labs 公式サイト

GitHub Pages で公開する静的サイト（https://humashibusiness-collab.github.io/）。
このリポジトリは**公開**。秘密情報・本名・住所・未発表の情報は入れない。

- `index.html` 作品一覧・連絡先 / `press.html` 配信・取材の方へ / `privacy.html` プライバシーポリシー
- 画像は `assets/`（各作品の素材から縮小）。作品を追加・発売したら、カードと press の資料を足す。
- 二次創作の無料版（ガッシュ・聖杯戦争・ちいかわ・DEATH NOTE）は 11/3 の公開後に載せるか判断する（今は載せていない）。
